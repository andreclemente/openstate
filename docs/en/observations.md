## How to read these observations

Each card shows:

- **Country** — where the problem was observed
- **Area** — the public service sector
- **Status** — the verification level of the observation
- **Sources** — how many evidence sources support the observation
- **Relations** — links to related observations

### Statuses

| Status | Meaning |
|:-------|:--------|
| **Draft** | Observation described, awaiting more evidence |
| **Confirmed** | Evidence attached, observation verifiable |
| **Analyzed** | Root cause identified, impact documented |
| **Proposed** | Structured solution submitted |

---

This is what OpenState documents. Every observation is a step toward making visible the patterns that affect millions of people.
