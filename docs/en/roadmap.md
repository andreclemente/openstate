# Roadmap

OpenState is a young project. Here's where we're heading — and how you can help.

---

## Now

- ✅ Bilingual documentation (EN + PT)
- ✅ Structured issue templates
- ✅ Auto-translation workflow
- ✅ Dark mode support
- ✅ Quick Start guide
- ✅ Changelog

## Next

- 🔄 **Search improvements** — Better discoverability of issues and documentation
- 🔄 **Issue quality scoring** — Community-driven quality assessment for issues
- 🔄 **Labels automation** — Auto-suggest labels based on issue content

## Future

- 📋 **API for structured data** — Programmatic access to issues and evidence
- 📋 **Issue linking** — Formal relationships between related problems
- 📋 **Evidence archive** — Permanent storage for evidence documents
- 📋 **Multi-language support** — Beyond EN/PT
- 📋 **Community voting** — Prioritize issues by community impact

---

## How to contribute

Want to help with any of these? Here's how:

1. **Pick an item** from the list above
2. **Open an issue** using the [Meta template](https://github.com/andreclemente/openstate/issues/new?template=meta.yml)
3. **Start working** — we'll connect you with other contributors

All contributions are welcome — code, documentation, design, or just feedback.
