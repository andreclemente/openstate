# Changelog

All notable changes to the OpenState project are documented here.

---

## 2026-06-12

### Added

- **Evidence Guide** — New bilingual (EN/PT) guide teaching users how to find, evaluate, and present evidence for issues
- **Issue state badges** — Visual badge references (shields.io) for Draft/Confirmed/Analyzed/Proposed states on How It Works pages
- **Good First Issue starter tasks** — 3 curated beginner-friendly issues to help new contributors get started (#7, #8, #9)
- **Open Graph & Twitter Card meta tags** — Social sharing now shows a rich preview with title, description, and image
- **Dark mode support** — Toggle between light and dark themes using the theme picker
- **Last updated timestamps** — Each documentation page now shows when it was last modified
- **Quick Start guide** — New 3-step guide to help first-time contributors get started
- **Project Roadmap** — Public roadmap showing planned improvements and how to contribute
- **Examples in navigation** — Examples page is now accessible from the main navigation
- **Examples page "Report a Problem" link** — Added consistent CTA to Examples page

---

## 2026-06-11

### Added

- **Initial documentation structure** — English and Portuguese documentation
- **Issue templates** — Report Problem, Solution Proposal, and Meta Discussion templates
- **Auto-translation workflow** — Portuguese issues automatically translated to English via GitHub Actions
- **Examples page** — Structured examples for Healthcare, Education, and Digital Services
- **Contributing guidelines** — Clear rules for what is accepted and rejected
- **Labels system** — Sector, Type, Urgency, and State labels for organizing issues
