# Quick Start

Get started with OpenState in 3 steps.

---

## Step 1: Identify a problem

Think of a public service that doesn't work as expected. It could be:

- A long wait time at a hospital
- A redundant bureaucratic process
- A digital service that doesn't work properly
- An accessibility barrier

**The key:** It must be observable and reproducible — not just an opinion.

---

## Step 2: Document it

Use the structured issue template to document the problem:

### [🐛 Report a Problem](https://github.com/andreclemente/openstate/issues/new?template=reportar-problema.yml)

Include:

- **What** is the problem?
- **Who** is affected?
- **What** is the impact (time, cost, complexity)?
- **What** evidence supports this?

Write in **Portuguese or English**. Auto-translation is included.

---

## Step 3: Engage with the community

- Browse existing issues to avoid duplicates
- Add evidence to issues in `Draft` state
- Propose solutions for issues in `Analyzed` state
- Discuss root causes in issue comments

### [💡 Submit a Solution Proposal](https://github.com/andreclemente/openstate/issues/new?template=proposal.yml)
