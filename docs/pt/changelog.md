# Histórico de Alterações

Todas as alterações notáveis no projeto OpenState são documentadas aqui.

---

## 2026-06-12

### Adicionado

- **Meta tags Open Graph e Twitter Cards** — Partilha em redes sociais mostra agora uma pré-visualização rica com título, descrição e imagem
- **Suporte para modo escuro** — Alternar entre tema claro e escuro usando o seletor de tema
- **Timestamps de última atualização** — Cada página de documentação mostra quando foi modificada pela última vez
- **Guia de Início Rápido** — Novo guia de 3 passos para ajudar novos contribuidores
- **Roadmap do projeto** — Roadmap público com melhorias planeadas e como contribuir
- **Exemplos na navegação** — Página de Exemplos acessível a partir da navegação principal
- **Link "Reportar Problema" na página de Exemplos** — CTA consistente adicionado

---

## 2026-06-11

### Adicionado

- **Estrutura inicial de documentação** — Documentação em Inglês e Português
- **Templates de issues** — Reportar Problema, Proposta de Solução e Meta Discussão
- **Workflow de tradução automática** — Issues em português traduzidas automaticamente para inglês via GitHub Actions
- **Página de exemplos** — Exemplos estruturados para Saúde, Educação e Serviços Digitais
- **Guidelines de contribuição** — Regras claras para o que é aceite e rejeitado
- **Sistema de labels** — Labels de Setor, Tipo, Urgência e Estado para organizar issues
