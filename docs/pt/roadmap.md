# Roadmap

O OpenState é um projeto jovem. Aqui está para onde vamos — e como podes ajudar.

---

## Agora

- ✅ Documentação bilingue (EN + PT)
- ✅ Templates estruturados de issues
- ✅ Workflow de tradução automática
- ✅ Suporte para modo escuro
- ✅ Guia de Início Rápido
- ✅ Histórico de alterações

## A seguir

- 🔄 **Melhorias de pesquisa** — Melhor descobribilidade de issues e documentação
- 🔄 **Pontuação de qualidade** — Avaliação comunitária da qualidade das issues
- 🔄 **Automação de labels** — Sugestão automática de labels baseada no conteúdo

## Futuro

- 📋 **API para dados estruturados** — Acesso programático a issues e evidências
- 📋 **Ligação de issues** — Relações formais entre problemas relacionados
- 📋 **Arquivo de evidências** — Armazenamento permanente para documentos de evidência
- 📋 **Suporte multi-idioma** — Para além de EN/PT
- 📋 **Votação comunitária** — Priorizar issues por impacto comunitário

---

## Como contribuir

Queres ajudar com algum destes itens? Aqui está como:

1. **Escolhe um item** da lista acima
2. **Abre uma issue** usando o [template Meta](https://github.com/andreclemente/openstate/issues/new?template=meta.yml)
3. **Começa a trabalhar** — vamos ligar-te a outros contribuidores

Todas as contribuições são bem-vindas — código, documentação, design ou apenas feedback.
