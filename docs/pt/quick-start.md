# Início Rápido

Começa com o OpenState em 3 passos.

---

## Passo 1: Identifica um problema

Pensa num serviço público que não funciona como esperado. Pode ser:

- Um tempo de espera longo num hospital
- Um processo burocrático redundante
- Um serviço digital que não funciona corretamente
- Uma barreira de acessibilidade

**A chave:** Deve ser observável e reproduzível — não apenas uma opinião.

---

## Passo 2: Documenta-o

Usa o template estruturado de issue para documentar o problema:

### [🐛 Reportar um Problema](https://github.com/andreclemente/openstate/issues/new?template=reportar-problema.yml)

Inclui:

- **O que** é o problema?
- **Quem** é afetado?
- **Qual** é o impacto (tempo, custo, complexidade)?
- **Que** evidências suportam isto?

Escreve em **Português ou Inglês**. Tradução automática incluída.

---

## Passo 3: Participa na comunidade

- Procura issues existentes para evitar duplicações
- Adiciona evidências a issues no estado `Rascunho`
- Propõe soluções para issues no estado `Analisado`
- Discute causas raiz nos comentários das issues

### [💡 Submeter Proposta de Solução](https://github.com/andreclemente/openstate/issues/new?template=proposal.yml)
