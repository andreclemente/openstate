# Contribuir

Se viveste um problema num serviço público, podes documentá-lo. Basta descrever o que aconteceu e incluir provas.

Uma boa observação é:
- **concreta** — descreve uma situação real, não uma opinião geral
- **documentada** — inclui fontes verificáveis (notícias, relatórios, dados públicos)
- **neutra** — sem linguagem política ou ideológica
- **única** — uma observação por situação. Se for semelhante a outra, confirma-se a existente

Uma má observação:
- contém dados pessoais de terceiros
- usa linguagem política ou partido
- descreve opiniões sem evidência
- tenta resolver o problema em vez de o documentar

---

## Como submeter

**1.** Cria uma conta em [github.com](https://github.com) (gratuito).

**2.** Abre uma nova observação (issue) no repositório do OpenState.

**3.** Preenche o formulário — descreve a situação, inclui fontes, escolhe a área do serviço.

**4.** Submete. A observação é revista e publicada no site.
