## Como ler estas observações

Cada cartão mostra:

- **País** — onde o problema foi observado
- **Área** — o sector do serviço público
- **Estado** — o nível de verificação da observação
- **Fontes** — quantas fontes de evidência suportam a observação
- **Relações** — ligações a observações relacionadas

### Estados

| Estado | Significado |
|:-------|:------------|
| **Rascunho** | Observação descrita, aguarda mais evidência |
| **Confirmado** | Evidência anexada, observação verificável |
| **Analisado** | Causa raiz identificada, impacto documentado |
| **Proposto** | Solução estruturada submetida |

---

Isto é o que o OpenState documenta. Cada observação é um passo para tornar visíveis os padrões que afectam milhões de pessoas.
